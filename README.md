# A000104: Free Polyominoes Without Holes

Programs for counting free polyominoes without holes ([A000104](http://oeis.org/A000104)).

Python program in `python/` directory

Rust program in `rust/` directory

Algorithm description and writeup in `tex/` directory

Expanded b-files, Jensen's series, and the run outputs in the `data/` directory: `b000104.txt` and `b006724.txt` are this program's b-files to n = 46; `b*.original.txt` are the OEIS b-files, kept for the checks, and `b006724.original.ERROR.txt` is the OEIS A006724 b-file, whose F(42) is wrong
